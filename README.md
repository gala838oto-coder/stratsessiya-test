# Стратсессия · тестовый сбор данных

Самодостаточная HTML-страница для живого теста методологии сбора данных перед стратегической сессией: анкета участника + сводка модератора. Без сервера и регистрации.

**Открыть онлайн:** https://gala838oto-coder.github.io/stratsessiya-test/

## Как провести тест

1. **Участники** открывают ссылку (или сканируют QR-код), заполняют анкету. Блок 01 «Где узкое место» — обязательный, остальное можно пропускать.
2. После отправки участник нажимает **«Скачать мои ответы (JSON)»** и присылает файл модератору (почта, мессенджер — любым способом).
3. **Модератор** на своём компьютере открывает вкладку **СВОДКА** → **«Импорт JSON»** → выбирает все присланные файлы разом. Сводка пересчитывается автоматически.
4. Если участник заполняет анкету прямо на компьютере модератора — файл не нужен, ответы уже в сводке.

## Что видит сводка

- общая статистика: сколько анкет, кто главный кандидат в ограничения;
- сводные баллы звеньев (0–100, обратные вопросы перевёрнуты), статусы «ограничение / наблюдение / в норме», флаг σ ≥ 2.5 (нет единой картины по звену), число гипотез по звену;
- все гипотезы об узком месте (анонимно);
- ресурс команды (средние), ретроспектива (анонимно), ожидания (анонимно);
- **благодарности — поимённо, только модератору** (зафиксированное решение: группе не показываем).

## Данные для анализа

- **Экспорт JSON** — полная копия всех собранных анкет (резервная копия / перенос на другой компьютер через «Импорт JSON»).
- **Экспорт CSV** — оценки в длинном формате (строка = участник × звено), открывается в Excel.
- Данные хранятся только в браузере (localStorage). Перед очисткой кеша браузера сделайте экспорт JSON.

## Локальный запуск

Файл `index.html` работает и без интернета: просто откройте его двойным кликом в любом браузере.
